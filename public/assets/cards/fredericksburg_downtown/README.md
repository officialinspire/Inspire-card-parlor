Built by `scripts/art/extract_cards.py` from `art/sources/Downtown Fredericksburg Collector Deck.png` (1536×1024). Do not edit these files by hand; replace the source sheet and run `npm run art:cards`.

| -------------- | ------------------------------------------------------------ |
| `faces.webp`   | 52 faces, 13 × 4 grid (A…K; ♠ ♥ ♦ ♣), 135×209 px cells       |
| `back.webp`    | card back                                                    |
| `extras.webp`  | jokers (not used by the five games)                          |
| `preview.webp` | catalog preview fan                                          |
| `atlas.json`   | source frame of every card, identity checks and review notes |

Source row order: clubs, diamonds, hearts, spades. Faces verified: 52/52.

## Artwork notes

- The card back is drawn landscape; it is turned upright for play, so its title reads sideways. A portrait back is recommended.
- Both jokers are shorter than the other cards (they appear cut off by the bottom of the sheet). Jokers are not used by the five games.
